# hds_curated_assets

Curated assets code developed by the BHF DSC health data scientists

Curated assets are reusable, analysis-ready tables built from underlying source datasets in the NHS England Secure Data Environment. They go beyond basic tidying to provide harmonised structures, consistent definitions and simple quality checks, so that common tasks do not need to be repeated in every project. Some assets (e.g. the Key Patient Characteristics tables) provide standardised demographics for all projects; others (e.g. covid_positive, hes_apc_diagnosis, or deaths tables) consolidate and reshape multiple raw tables into a single, well-documented resource. These assets can be used directly in project pipelines or for exploratory data analysis, giving researchers a consistent starting point and improving comparability across studies.

## How to cite

Please cite all uses of curated assets, e.g.
“Core data for this project were derived from the BHF Data Science Centre curated assets (British Heart Foundation Data Science Centre at Health Data Research UK), documented at https://bhfdsc.github.io/documentation/curated_assets, accessed 29 July 2025.”
For additional information see our Publication and Dissemination Policy (https://bhfdatasciencecentre.org/publication-and-dissemination-policy/).
